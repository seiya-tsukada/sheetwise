# サンプルデータ

## sales_2025.csv

2025年1月〜12月の架空のB2B受注データ（742行 × 13列, UTF-8）。
`python3 sample/generate_sales_2025.py sample/sales_2025.csv` で同じ内容を再生成できます（乱数シード固定）。

| カラム | 想定される推定ロール | 内容 |
| --- | --- | --- |
| 注文ID | id | `ORD-00001` 形式 |
| 注文日 | date | 2025-01-01〜2025-12-31（期間 > 180日 → 月次集計） |
| 地域 | category | 6種類（東京に売上が集中） |
| 商品カテゴリ | category | 5種類 |
| 販売チャネル | category | 3種類 |
| 会員フラグ | boolean | 0 / 1 |
| 売上 | metric | 単価 × 数量 × (1 − 割引率) |
| 広告費 | metric | 売上と強い正の相関、約7%欠損 |
| 数量 | metric | |
| 単価 | metric | |
| 割引率 | metric | 0 / 0.05 / 0.10 / 0.15 |
| 顧客満足度 | metric | 1.0〜5.0、約3%欠損 |
| 備考 | category | 約61%欠損 |

## 検証できる分析ロジック

- **時系列推移**: 月次売上は12月がピーク、1月がボトム。12月は前月比 約+27%（トレンド方向 = up）
- **カテゴリ比較**: 地域別売上は東京が約35%、上位3地域で約70%
- **相関分析**: 売上 × 広告費 で r ≈ 0.77（strong / positive）
- **分布の偏り**: 売上は平均 > 中央値（右に裾の長い分布）
- **データ品質**
  - 完全重複行 4件
  - 欠損: 備考（high）、広告費（medium）
  - 外れ値候補: 数量40〜60の大口受注（備考 = 法人一括）など
- **グラフ推薦**: 日付×指標の折れ線、カテゴリ別の棒/円、売上×広告費の散布図など

## hr_2025.csv

架空の組織人事データ。2025-12-31 時点の社員名簿スナップショット（795行 × 16列, UTF-8）。
`python3 sample/generate_hr_2025.py sample/hr_2025.csv` で同じ内容を再生成できます（乱数シード固定）。
売上データ（取引ログ・単一年）と違い、「人」単位のスナップショットで、日付軸が20年にわたる点・カテゴリ数が多い点で分析結果の見え方が変わります。

| カラム | 想定される推定ロール | 内容 |
| --- | --- | --- |
| 社員番号 | id | `EMP-0001` 形式 |
| 入社日 | date | 2005-04-01〜2025-12（期間 約20年 → 月次集計） |
| 部署 | category | 6種類（開発に約39%が集中） |
| 役職 | category | 一般 / 主任 / 課長 / 部長 / 役員 |
| 雇用形態 | category | 正社員 / 契約社員 / 派遣 |
| 勤務地 | category | 4種類（東京本社が約52%） |
| リモート勤務 | boolean | 0 / 1 |
| 年収（万円） | metric | 役職・勤続年数で上昇、右に裾の長い分布 |
| 月平均残業時間 | metric | 役員は空欄（管理対象外） |
| エンゲージメントスコア | metric | 1.0〜5.0、約9%欠損（サーベイ未回答） |
| 有給取得率 | metric | 0〜1 |
| 勤続年数 | metric | 入社日から算出 |
| 年齢 | metric | |
| 研修受講時間 | metric | 若手ほど多い |
| 人事評価 | category | S / A / B / C / D（B が最多） |
| 備考 | category | 約85%欠損 |

### 検証できる分析ロジック

- **時系列推移**: 入社人数は年々増加（2005年 6人 → 2025年 83人）し、毎年4月（新卒一括入社）に突出したピーク、10月に小さな山
- **カテゴリ比較**: 部署別人数は開発が約39%、上位3部署で約76%
- **相関分析**
  - 月平均残業時間 × エンゲージメントスコア で r ≈ −0.74（strong / negative）
  - 勤続年数 × 年収 で r ≈ 0.68（正の相関）
  - 月平均残業時間 × 有給取得率 で r ≈ −0.38（弱〜中程度の負の相関）
- **分布の偏り**: 年収は平均（約664万円）> 中央値（590万円）
- **データ品質**
  - 完全重複行 3件（人事システム移行時の二重登録を想定）
  - 欠損: 備考（high）、エンゲージメントスコア（medium）、月平均残業時間（役員のみ・low）
  - 外れ値候補: 月平均残業時間 75〜95時間の社員6名（備考 = 長時間労働面談対象）、役員の年収
