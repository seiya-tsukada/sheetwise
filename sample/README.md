# サンプルデータ

## sales_2025.csv

2025年1月〜12月の架空のB2B受注データ（742行 × 13列, UTF-8）。
`python3 sample/generate_sales_2025.py sample/sales_2025.csv` で同じ内容を再生成できます（乱数シード固定）。

| カラム | 想定される推定ロール | 内容 |
| --- | --- | --- |
| 注文ID | id | `ORD-00001` 形式 |
| 注文日 | date | 2025-01-01〜2025-12-31（期間 > 180日 → 月次集計） |
| 地域 | category | 6種類（東京に売上が集中） |
| 商品カテゴリ | category | 5種類 |
| 販売チャネル | category | 3種類 |
| 会員フラグ | boolean | 0 / 1 |
| 売上 | metric | 単価 × 数量 × (1 − 割引率) |
| 広告費 | metric | 売上と強い正の相関、約7%欠損 |
| 数量 | metric | |
| 単価 | metric | |
| 割引率 | metric | 0 / 0.05 / 0.10 / 0.15 |
| 顧客満足度 | metric | 1.0〜5.0、約3%欠損 |
| 備考 | category | 約61%欠損 |

## 検証できる分析ロジック

- **時系列推移**: 月次売上は12月がピーク、1月がボトム。12月は前月比 約+27%（トレンド方向 = up）
- **カテゴリ比較**: 地域別売上は東京が約35%、上位3地域で約70%
- **相関分析**: 売上 × 広告費 で r ≈ 0.77（strong / positive）
- **分布の偏り**: 売上は平均 > 中央値（右に裾の長い分布）
- **データ品質**
  - 完全重複行 4件
  - 欠損: 備考（high）、広告費（medium）
  - 外れ値候補: 数量40〜60の大口受注（備考 = 法人一括）など
- **グラフ推薦**: 日付×指標の折れ線、カテゴリ別の棒/円、売上×広告費の散布図など
